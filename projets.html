Application web PHP

M2L - Site dynamique

GitHub

Application dynamique pour la Maison des Ligues permettant de consulter et gérer les ligues, clubs, utilisateurs et formations. Le projet repose sur PHP orienté objet, MySQL et une organisation MVC avec contrôleurs, vues, DAO et DTO.

Objectifs

  • Transformer un site statique en application dynamique.
  • Gérer les ligues, clubs et formations depuis une base MySQL.
  • Mettre en place des rôles utilisateur et des droits d'accès.

Difficultés rencontrées

  • Structuration MVC et séparation claire DAO / DTO.
  • Gestion des formulaires de création, modification et suppression.
  • Maintien de la cohérence des données entre ligues, clubs et communes.

Solutions apportées

  • Création de contrôleurs dédiés par fonctionnalité.
  • Requêtes SQL préparées via une connexion PDO centralisée.
  • Pages adaptées aux profils secrétaire, salarié et responsable.

API REST PHP

AP Armée - API de tournois

GitHub

API REST en PHP pour gérer des utilisateurs, tournois, équipes, rounds et matchs. Le service utilise une authentification Bearer par JWT, des routes JSON et des DAO connectés à une base MySQL.

Objectifs

  • Créer une API conforme à un contrat fourni.
  • Protéger les routes via un token d'authentification.
  • Permettre le CRUD sur les tournois, équipes et matchs.

Difficultés rencontrées

  • Gestion des routes avec paramètres dynamiques.
  • Vérification du token avant l'accès aux données protégées.
  • Organisation des DAO pour plusieurs entités liées.

Solutions apportées

  • Router centralisé dans l'entrée API.
  • Classe Token dédiée à la création et vérification JWT.
  • Tests Postman des endpoints principaux.

Stage 1ère année - Directus

Page professionnelle multilingue

Développement d'un module métier pendant le stage de première année pour gérer des pages professionnelles dans Directus. La solution permet de saisir un profil, d'associer un utilisateur, d'ajouter des traductions par langue et d'afficher des onglets personnalisés sur une page publique.

Objectifs

  • Modéliser les données nécessaires à une page professionnelle dans Directus.
  • Permettre la gestion des traductions de métier et d'informations complémentaires.
  • Afficher une fiche publique claire avec sélecteur de langue et onglets personnalisés.

Difficultés rencontrées

  • Concevoir les relations entre utilisateurs, pages professionnelles, langues et traductions.
  • Synchroniser le contenu saisi dans Directus avec l'affichage de la page publique.
  • Structurer des onglets personnalisés exploitables côté administration comme côté visiteur.

Solutions apportées

  • Création d'un schéma relationnel clair avec collection de traductions dédiée.
  • Mise en place d'une interface Directus simple pour l'édition du contenu.
  • Validation fonctionnelle du rendu final avec sélection de langue et restitution des onglets.

2ème stage 2ème année - GLPI

Gestion des unités contractuelles

Personnalisation de GLPI réalisée pendant le second stage de deuxième année pour suivre la consommation d'unités sur les contrats CPU. Le projet relie les tickets aux contrats, historise les interventions, gère les avenants et reports, puis affiche un tableau de bord de suivi directement dans l'interface web.

Objectifs

  • Centraliser le suivi des unités consommées par contrat dans GLPI.
  • Lier les tickets et interventions au décompte d'unités selon le niveau technicien.
  • Afficher l'historique, le solde, les reports et la progression d'usage.

Difficultés rencontrées

  • Comprendre la structure des données GLPI et identifier les bonnes tables SQL.
  • Faire circuler les informations entre les écrans de ticket, les contrats et l'historique des unités.
  • Rendre le suivi lisible pour les techniciens avec des synthèses et des exports exploitables.

Solutions apportées

  • Analyse et vérification des données via des requêtes SQL ciblées sur les tables de contrats.
  • Ajout d'interfaces dédiées pour la gestion des unités, l'historique et les avenants ou reports.
  • Mise en place d'un tableau de bord avec indicateurs, progression de consommation et actions d'export.

Game Jam - Godot

Mask Jam

GitHub itch.io

Prototype de jeu 2D réalisé pendant une Game Jam. Le gameplay repose sur un personnage capable de changer de masque pour modifier ses interactions avec l'environnement, gérer un inventaire et progresser dans une ambiance pixel art.

Objectifs

  • Produire un prototype jouable dans un temps limité.
  • Créer une mécanique centrale autour des masques.
  • Intégrer sprites, sons, scènes et interface utilisateur.

Difficultés rencontrées

  • Coordonner rapidement plusieurs branches Git pendant la jam.
  • Gérer les effets des masques sur les collisions et interactions.
  • Assembler gameplay, inventaire, menus et ambiance sonore.

Solutions apportées

  • Scripts GDScript dédiés au joueur, à l'inventaire et aux masques.
  • Utilisation de scènes Godot pour isoler les éléments du jeu.
  • Gestion des inputs clavier et des changements de masque en jeu.
